# 15 · 每日群报与亲密度

> 这一轮加两样：**每天给群写一份简报**（群报）、**记住和每个人的关系**（亲密度）。

---

## 一、每日群报

### 是什么

每天固定时间（默认 22:30），把群里今天的话题、趣事、约好的事整理成 2~3 条简报：

```
📮 今日群报
- 小明在群里晒了新猫，大家开始比猫
- 约好了周五晚上聚餐
- 有人还在赶论文，祝顺利
```

### 怎么开

```yaml
chat:
  daily_report:
    enabled: true      # 默认 false，想每天总结就改 true
    hour: 22
    minute: 30
    groups: []         # 空 = 当天有消息的群都发
    min_messages: 8    # 当天消息少于这么多条就不发
    max_items: 3
```

默认**关闭**（避免打扰群），开了之后每天每群最多一条。

### 怎么实现

- `src/daily_report.py`：`REPORT_SYSTEM` 生成提示词（只根据真实记录、不编造）
  + `DailyReportScheduler`（每分钟检查，到点后给目标群各发一次，`_last_day` 防止一天多次）；
- `src/memory.py`：新增 `messages_since()`，从「活动消息 + 归档原文」里取当天记录；
- `src/chat.py`：`send_daily_report()`（拼当天记录 + 长期摘要 → 调模型 → 清洗成 2-3 条 → 发送）
  和 `active_group_sessions()`（找出当天有消息的群）；
- 少消息的群自动跳过；群被静音也不发。

## 二、亲密度

### 是什么

每群每个人和她的互动累计一个亲密度：

| 分数 | 等级 | 表现 |
| --- | --- | --- |
| 0-9 | 陌生鱼 | 客气、短 |
| 10-39 | 熟鱼片 | 会接梗 |
| 40-99 | 老鱼片 | 更随便、会互损 |
| 100+ | 饲养员 | 最熟，可以黏人/撒娇 |

- 每次正常回复 **+1**，被戳也 +1（`chat.affinity.bump_per_reply` 可调）；
- 每群、每个人独立统计，存在 `affinity` 表；
- 注入上下文时告诉模型「你和 XX 的亲密度：23（熟鱼片）——关系越熟，说话可以越随便、越黏一点」；
- 群友发 `/affinity`（或 `/亲密度`）看自己的分数、等级和本群排行。

### 怎么实现

- `src/memory.py`：`affinity` 表 + `bump_affinity` / `get_affinity` / `top_affinity`；
- `src/chat.py`：`_bump_affinity()`（回复后累计）、`_memory_notes()` 注入、`/affinity` 命令、
  `_affinity_level()` 等级映射；
- `src/config.py`：`AffinityConfig`（`chat.affinity`）。

## 三、语音消息：这轮试了但没做成

- `edge-tts` 已装，但微软 TTS 服务返回 **403**（地区/网络限制），合成失败；
- Windows SAPI：本机**没有安装任何语音引擎**（`GetInstalledVoices` 空引用）；
- 结论：这台机器暂时发不了语音。要加语音需要：可用的 TTS API key（如火山/讯飞/Azure），
  或者本地安装 SAPI 中文语音包。代码可以后面再加（OneBot 发 `record` 段即可）。
