# 10 · 说话人识别（用 QQ 号区分每个人）

> 问题：群里出现「把不同的人当同一个人」——两个人昵称一样、或者有人改名片，
> 模型看到的历史只有昵称，于是把 A 说的话当成 B 说的，用户笔记也容易错位。
>
> 解决：**所有进入模型的地方，统一用「昵称（QQ 号）」标记说话人**；同一个人改昵称按 QQ 合并，
> 不同人即使昵称一样也能分开。

---

## 1. 三处上下文都带 QQ 号

| 位置 | 以前 | 现在 |
| --- | --- | --- |
| 当前这条消息 | 群聊有 `（QQ 123）`，私聊没有 | 群聊/私聊都带：`小明（QQ 20001）在群里说：…` / `小明（QQ 20001）私聊说：…` |
| 群聊背景缓存 | `小明: 在吗` | `小明（QQ 20001）: 在吗` |
| 会话历史（SQLite `messages.name`） | 只存昵称 | 存 `小明（QQ 20001）`，回放/摘要/记忆管家都会带上 |
| 用户笔记标题 | `【关于 小明 的笔记】` | `【关于 小明（QQ 20001）的笔记】`（笔记本来按 `user_id` 存） |

这样一来：

- **同名不同人**：两个「小明」在上下文里分别标着各自 QQ，模型不会混；
- **同一人改昵称**：历史里会出现旧昵称，但 QQ 号一致，模型能认出是同一人；
- **笔记/画像**：按 `user_id` 存，标题带 QQ，不会把 A 的偏好记到 B 头上。

## 2. 新增「本群最近说话的人」花名册

`GroupHistory` 会记录最近说话的人，每个群取最近 8 个活跃成员，注入上下文：

```
【本群最近说话的人】
- 小明（QQ 20001）
- 阿瓜（QQ 20002）
- 小张（QQ 20003）
```

好处：模型不只是看到"当前这条是谁说的"，还知道这个群大概有哪几个人、谁经常在，
称呼和上下文更稳定。花名册在内存里（重启后随聊天重新积累），会话历史和笔记仍然持久化。

## 4. 验证

```powershell
cd D:\蓝瑟大肥鱼\qq-deepseek-bot
python scripts/smoke_test.py     # 全量 155 项，其中 [20] 说话人识别 9 项
```

`[20]` 覆盖：

- 标签格式（有 QQ / 没 QQ 两种）；
- 同一昵称、不同 QQ → 两条都保留；
- 同一个人换昵称 → 只算一个人，且显示最新昵称；
- 群聊背景渲染带 QQ；
- 两个同名的人各说一句话 → 模型上下文里出现两个不同 QQ；
- 花名册注入；
- 会话历史 `name` 字段带 QQ；
- 私聊上下文也带 QQ 身份。
