# 18 · 活跃度曲线

> 成绩单上多了「近 7 天活跃」：每天群里说了多少话，一眼看到。

---

## 一、数据从哪来

`src/memory.py` 新增 `daily_message_counts(days=7, session_id=None)`：

- 把「活动消息表 + 归档原文表」按天聚合（`date(ts, 'unixepoch', 'localtime')`）；
- 没有消息的天补 0，保证固定 7 项（含今天）；
- 可指定会话；不指定就是全部群。

实测数据：10-22 1016 条 → 10-23 838 → 10-24 312 → 10-25 164（当天进行中），
一眼能看出哪天聊得最凶。

## 二、展示位置

| 位置 | 样子 |
| --- | --- |
| 成绩单图片（`/card`） | 「近 7 天活跃」柱状图，今天高亮，每根柱子下面写条数，右上角「共 N 条」 |
| 成绩单页面（`/dashboard`） | 单独一张卡片，柱状条 + 每天条数 + 日期 |

同一份 `dashboard_data()["activity_days"]`，图片和网页各自渲染。
