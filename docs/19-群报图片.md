# 19 · 群报图片（每日群报二合一）

> 上一轮是文字群报，这一轮把它画成图片：标题 + 今日看点 + 数据脚注，每天 22:30 直接发一张图。

---

## 一、效果

```
┌──────────────────────────────┐
│ 今日群报                      │
│ 2026-10-25 22:30 · 蓝色大肥鱼整理 │
│ ──────────────────────────── │
│ ● 小明在群里晒了新猫，大家开始比猫 │
│ ● 约好了周五晚上聚餐，地点还没定   │
│ ● 有人还在赶论文，祝顺利         │
│                              │
│ 今日消息 164 条 · 由大肥鱼自己生成 │
└──────────────────────────────┘
```

- 深蓝渐变 + 圆角圆点，和成绩单图片同一套风格；
- 文字自动换行，图片高度随内容自适应（2 条约 480px，5 条约 700px）；
- 渲染实测 **0.07 秒 / 约 43 KB**。

## 二、怎么开

```yaml
chat:
  daily_report:
    enabled: false      # 默认关闭，想每天发就改 true
    hour: 22
    minute: 30
    as_image: true      # 发图片版群报（失败自动退回文字）
    min_messages: 8
    max_items: 3
```

- `as_image: true` 时：生成群报 → 画图 → 发图片（不再额外发文字，图里已经全了）；
- 画图失败或 sender 不支持发图 → 自动退回纯文字群报，不会静默丢失；
- 手动 `/report` 同样遵循 `as_image`。
