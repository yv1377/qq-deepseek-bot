# 24 · 关心语润色与群报关心小注

> 上一轮的主动关心用的是固定台词池；这一轮让模型按**具体事件**写一句，
> 再把「最近在关心谁」画进群报图片。

---

## 一、关心语从台词池 → 模型生成

`llm.care_line(name, kind, detail)`：

```
你是一个群聊机器人，说话自然、有点黏人但不肉麻。
群友「小明」最近说：「感冒」（类型：sick）。
写一句 20~40 字的关心话：像朋友随口问一句，自然、不鸡汤、不用 emoji、不要引号。
```

- 温度 0.9、max_tokens 120，一次约几分钱；
- 生成结果过 `_clean_care_line()`：去引号、`scrub_output` 安全检查、截断 60 字；
- **模型失败/为空自动回退台词池**（不会因为 API 抖动就漏掉关心）；
- 走 `_session_usage_hook` 记在当日预算里。

实际效果对比：

| 之前（台词池） | 现在（模型生成，示例） |
| --- | --- |
| 身体怎么样了？别硬撑，难受就去看看。 | 感冒还难受吗？今天多睡会儿，别急着干活。 |

## 二、群报图片加「最近在关心」

群报图片在今日热词下面多一行粉色小字：

```
最近在关心：@小明（身体不舒服）、@小红（在准备考试）
```

- 取最近 7 天的关心事件、最多 3 条；
- 只显示昵称 + 类型标签，不暴露具体原话（隐私）。
