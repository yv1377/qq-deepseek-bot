# 22 · 手动触发群报与群报热词

> 这一轮：网页上点一下就能给某个群发群报；群报图片里也加上了「今日热词」。

---

## 一、WebUI「群报」卡片

成绩单页面（`/dashboard`）新增一个卡片：

```
群报
[群号________]  [立刻生成群报]
已发送到群 100000001
```

- 填群号、点按钮 → 调 `POST /api/report {"group_id": ...}` → `send_daily_report(force=True)`；
- **无视 `daily_report.enabled` 开关**（手动触发就该立即生效）；
- 当天消息太少 / 群被静音 → 返回 `{"ok": false}`，页面提示「今天消息太少或被静音，没发」。

## 二、群报图片加「今日热词」

`render_report_card()` 新增 `word_cloud` 参数：在活跃小图下方画一行今日热词（字号随出现次数变化，最多 10 个、自动换行）。

现在群报图片的结构是：

```
今日群报  (标题 + 时间 + 整理人)
● 看点 1 / ● 看点 2 / ● 看点 3
近 7 天活跃  ▁ ▁ ▁ █ ▅ ▂ ▁
今日热词   文字 看看 画面 喜欢 尾巴 …
今日消息 164 条 · 由大肥鱼自己生成
```

`send_daily_report()` 会把近 7 天群友消息交给 `build_word_cloud(top=10)`，和成绩单用同一套词云逻辑（自动过滤虚词/脏话）。

## 三、踩的坑：局部 Pydantic 模型导致 422

`ReportRequest` 一开始写在 `create_app()` 函数内部，FastAPI 把它当成了 **query 参数**，
POST 直接返回 422（`missing query payload`）。把它挪到模块级（和其他 `*Request` 模型放一起）后正常。
**规律：FastAPI 的请求体模型别定义在函数作用域里。**
