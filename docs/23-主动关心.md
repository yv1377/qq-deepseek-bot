# 23 · 主动关心

> 这一轮做点更「聪明」的：不再只是等别人问，而是从群聊里发现值得惦记的事，
> 过一两天主动问一句。全部规则匹配，不花模型钱。

---

## 一、触发的事

| 类型 | 关键词（示例） | 什么时候关心 |
| --- | --- | --- |
| 考试 | 考试/面试/答辩/考研/期末/月考 | 半天后（考完当天晚上） |
| 生病 | 感冒/发烧/不舒服/头疼/胃疼/住院 | 一天后 |
| 辛苦 | 加班/通宵/熬夜/赶工/ddl | 一天后 |
| 生日 | 「今天生日」等 | 立刻（当天） |
| 低落 | 失恋/分手/吵架/难过/emo/哭了 | 一天后 |

关心语按类型各有 2~3 句台词池（「身体怎么样了？别硬撑，难受就去看看。」这种），不会永远一句话。

## 二、防打扰（很重要）

主动发消息最容易招人烦，所以限制很严：

- **每人每 3 天最多一次**（`per_user_days`）；
- **每群每天最多 2 条**（`per_group_daily`）；
- **只在 9:00~23:00 发**（夜里不吵人）；
- 同一个人在 **24 小时内**同一件事只记一次（`dedupe_hours`）；
- 群被静音就不发；
- 只对群聊生效（私聊是用户自己找她，不需要主动）。

## 三、怎么实现

- `src/care.py`：关键词规则 `extract_care()`（纯正则，不调模型）、**关心语池**、
  `care_due()`（事件后多久关心）、`CareScheduler`（每 10 分钟查一次，白天才发）；
- `src/memory.py`：新增 `care_events` 表（session/user/name/kind/detail/due_at/sent/sent_at）
  与 adds/due/mark/计数/去重查询；
- `src/chat.py`：每条群消息顺手 `_note_care()`（匹配才写库，24 小时去重）；
  `send_care()` 做频控、拼「@昵称 + 关心语」发出；`stats.cares` 计数；
- `src/main.py`：启动/停止 `CareScheduler`；
- 成绩单接口新增 `care.pending`（未发出的关心事件数）。

## 四、配置

```yaml
chat:
  care:
    enabled: true          # 想关就改 false
    per_user_days: 3       # 每人多少天最多关心一次
    per_group_daily: 2     # 每群每天最多几条
    check_interval: 600    # 每多少秒检查一次
    dedupe_hours: 24       # 同一件事多少小时内不重复记
```

事件入库、未到期不关心、到期可查、未发送计数、夜间不发、到点主动关心（内容含昵称）、
发完标记、同一天不重复、聊天时自动记录、24 小时去重。
