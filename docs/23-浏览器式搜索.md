# 浏览器式搜索总结

## 用法

所有群都可以：

```text
/search 今天上海天气
/搜索 英雄联盟 S15 赛程
/查一下 大众点评是什么
```

也可以自然语言：

```text
帮我搜一下今天上海天气
你去网上看看最近有什么新闻
```

模型会调用 `web_search_summary` 工具，走完整链路：

1. Bing 网页 HTML 搜索，拿标题/摘要/链接；
2. 打开前两条来源网页，读取正文（只允许公开 http/https，拦内网/本机）；
3. 模型总结，附来源；资料不足就明说没查到，不编造。

## 说明

- 这是 **HTTP 抓取 + 网页正文提取**，不是本机 Chromium/Playwright；云端不用装大浏览器，
  但能拿到搜索结果和来源页正文，适合群聊里的实时查询。
- 需要 JS 渲染/登录的站点可能抓不到；要覆盖这类站点可另接 Playwright 或 Jina/Firecrawl。
- `/search` 每群 20 秒冷却，计入群预算。
- 自动搜索仍只对关键问题触发；普通闲聊不搜。

## 搜索词清洗（2026-10-26 修复）

- 去掉“帮我搜一下 / 去网上 / 告诉我 / 看看 / 一下 / 吗”等命令词和口语词；
- “赛事安排、比赛安排、赛事日程”统一成“赛程”；
- “今天/明天/后天”**不塞进搜索关键词**，只作为总结时的时间提示；
  例如“帮我搜一下明天的英雄联盟世界赛赛事安排”会变成“英雄联盟世界赛赛程”；
- 结果和问题不沾边时直接说没查到，不再把无关网页（例如“帮字怎么写”）当资料；
- 该清洗同时用于 `/search`、自动预搜和 `web_search_summary` 工具。
