# 11 · 防刷屏与防复读

> 需求：给自动回复加个上限——**连续多次发同一个消息，就不要回复了**。
>
> 这句话有两种可能的主体，两种都做了：
> 1. **群友刷屏**：同一个人连续复读同一句 → 她先不接（别被刷屏带着走）；
> 2. **机器人自己复读**：模型连续两次吐出同一句 → 后一次直接不发（防复读机）。

---

## 1. 群友连续复读：先不接

`chat.anti_spam` 配置：

```yaml
chat:
  anti_spam:
    enabled: true
    repeat_limit: 3          # 同一人 60 秒内重复同一句达到 3 次后不再回复（0 = 关闭）
    repeat_window: 60        # 统计窗口（秒）
    dedupe_replies: true     # 自己的回复和上一条完全相同就跳过
    reply_history: 5         # 每个会话记最近几条自己的回复
```

规则：

- 按「会话 + QQ 号」独立统计：群里 A 刷屏不影响 B，私聊也单独算；
- 归一化去掉空白和标点，所以「在吗」「在吗！」「在吗。。。」算同一句；
- 第 `repeat_limit` 次开始跳过回复（前两次照常回），窗口过去后自动恢复；
- 跳过时 `stats.suppressed + 1`，日志打印「连续重复消息，跳过回复」；
- 只影响"要不要接这句话"，不写记忆、不消耗模型额度。

实现位置：`src/policy.py` 的 `RepeatGuard` + `src/chat.py` 的 1.55 段检查。

## 2. 机器人自己复读：后一次不发

模型偶尔会卡住，连续两次输出同一段话（尤其上下文被截断时）。现在：

- 每个会话记最近 `reply_history` 条自己的回复（归一化后比较）；
- 新回复与**上一条**完全一样 → 跳过发送，`stats.suppressed + 1`，日志「回复与上一条重复，跳过发送」；
- 只拦"连续重复"，隔一句再说同样的话不受影响（正常的口头禅不会被误伤）。

实现位置：`src/chat.py` 的 `_is_repeated_reply` + 发送前检查。

## 3. 和已有保护的关系

| 机制 | 管什么 |
| --- | --- |
| `chat.group.burst_limit` | 回复频率（60 秒内最多回几条） |
| `chat.group.cooldown` / `per_minute` | 冷却与每分钟上限 |
| `chat.anti_spam.repeat_limit` | **同一句话反复刷** → 不接 |
| `chat.anti_spam.dedupe_replies` | **自己回复重复** → 不发 |
| `chat.budget` | 花费上限 |

## 4. 验证

```powershell
cd D:\蓝瑟大肥鱼\qq-deepseek-bot
python scripts/smoke_test.py     # 全量 169 项，其中 [22] 防刷屏 14 项
```

`[22]` 覆盖：

- 复读第 1、2 次不拦，第 3 次拦下；
- 换一句话不拦、换个人不拦；
- 标点不同视为同一句；
- 窗口过期后恢复；
- 集成：同一人连发 4 次「在吗」→ 只回 2 条（第 3、4 次被跳过）；
- 换个人同一句仍然回复；
- 自己回复重复时只发第一条，`suppressed` 计数增加。

## 5. 可调参数建议

- 想让机器人"更耐刷"：`repeat_limit: 2`（第 2 次就不接）；
- 想完全不管刷屏：`repeat_limit: 0`；
- 嫌它有时该回却不回：把 `dedupe_replies` 改成 `false`（只保留群友刷屏保护）；
- 群里喜欢复读玩梗、又不想让她跟着复读：保留默认值即可，她会在第 3 次之后闭嘴。
