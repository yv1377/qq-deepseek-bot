# 25 · 周报

> 群报是每天一张，周报是**每周一张**：这一周群里的消息量、活跃度、热词、最熟的人、看点。

---

## 一、长什么样

```
本周群报
10-18 ~ 10-25 · 蓝色大肥鱼整理
────────────────────────────
消息 2360 条 · 活跃 4 天 · 关心 0 人次
[10-19 ▁] [10-20 ▁] [10-21 ▁] [10-22 █] [10-23 ▆] [10-24 ▂] [10-25 ▂]
本周热词   文字 看看 画面 喜欢 你是 尾巴 主人 鱼姐
本周最熟   QQ3871324658 13（老鱼片）｜QQ2168046400 3（老鱼片）
本周看点
● 小明在群里晒了新猫，大家开始比猫…
● 约好了周五晚上聚餐…
────────────────────────────
由大肥鱼自己生成 · 每周一张 · /card 可看成绩单
```

数据全部来自真实记录：消息条数 / 活跃天数来自按天聚合，热词来自近 7 天群友消息，
「本周最熟」来自亲密度表，「关心」来自主动关心记录（本周内）。

## 二、怎么开

```yaml
chat:
  weekly_report:
    enabled: false      # 默认关闭，想每周回顾就改 true
    weekday: 6          # 0=周一 … 6=周日
    hour: 21
    minute: 0
    groups: []          # 空 = 当天活跃的群都发
    min_messages: 20    # 本周消息少于这么多条就不发
    max_items: 3
```

默认关闭（避免打扰）；开了之后每周最多给每个活跃群发一张。

## 三、实现

- `src/weekly.py`：`WEEKLY_SYSTEM`（本周看点提示词）+ `WeeklyReportScheduler`
  （每 10 分钟检查一次，只在配置的星期几 + 到点后发，`_last_day` 防一周多次）；
- `src/chat.py`：`send_weekly_report()` —— 取近 7 天消息/活跃/热词/亲密度/关心 →
  模型写 2-3 条看点 → 渲染图片 → 发送（群静音/消息太少跳过）；
- `src/card.py`：`render_weekly_card()`（标题/数据行/活跃柱状/热词/最熟/看点/脚注）；
- `src/main.py`：启动/停止周报调度器；
- 配置：`chat.weekly_report`。
