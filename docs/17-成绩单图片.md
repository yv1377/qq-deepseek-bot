# 17 · 成绩单图片（发到群里的那种）

> 上一轮做了网页版成绩单；这一轮把同一份数据**画成图片**，群友发 `/card` 就能收到一张图。

---

## 一、怎么用

群里（或私聊）发：

```
/card     或   /成绩单
```

她会把自己的数据渲染成一张 PNG 发出来（附一句「喏，我的成绩单。」），内容：

- 标题 + 日期 + 运行时长 + 模型
- 四个大数字：收到消息 / 回复 / 戳戳回复 / 出错
- 心情：每个群的能量条 + 标签
- 亲密度：每个群 top3（昵称 + 等级 + 分数）
- 今日预算：每个群花了多少 / 每天上限
- 记忆与图库：消息/归档/笔记/画像/待办、表情包/自画像/提醒数
- 本群热点词（近 7 天，字号 = 出现次数）
- 页脚：由大肥鱼自己生成

## 二、实现

| 文件 | 做什么 |
| --- | --- |
| `src/card.py` | 用 Pillow 绘制：深蓝渐变背景、圆角卡片、进度条、自适应高度（内容少就矮一点）、中文字体（微软雅黑/黑体，找不到自动降级） |
| `src/chat.py` | `/card` 命令 → 取 `dashboard_data()` → `render_card()` → 发图；**同一会话 5 分钟内复用上一张图**（不重复渲染） |
| `src/config.py` / `config.yaml` | `chat.card.enabled` / `cooldown_minutes` |
| `src/text_stats.py` | 词云里额外过滤脏话与 2-gram 噪声（「情包」「字为」这类），成绩单上没有脏话 |

渲染实测：**约 0.1 秒**、约 80 KB、高度 890~1120 自适应；字体缺失时用 Pillow 默认位图字体（中文会变方框，但不会崩）。

## 四、顺手修的一个偶发测试

`friend_test` 里「看不懂图反问」的断言只认「没看懂」，而台词池里有一条是「看不懂」，
随机抽到那条就偶发失败——已把断言放宽，连跑 5 次稳定通过。
