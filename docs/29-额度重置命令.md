# 29 · 主人一句话重置额度

> 目标：主人不想再手动改后台/数据库，在 QQ 里跟 Bot 说一句「重置额度」就立刻恢复当天额度。

---

## 一、为什么以前要手动改

`chat.budget` 按「群号 + 本地日期」把花费写进 `data/budget.db`，超过
`daily_cny_per_group` 后当天不再调模型。以前的清额度方式只有两种：

1. 跑脚本 `python scripts/reset_budget.py <群号>`；
2. 直接改数据库（且**运行中的 Bot 有内存缓存，改完还得重启**才生效）。

## 二、现在怎么用

配置里 `chat.admin.qq: [3871324658]`（主人号）。主人可以用命令，也可以直接用大白话：

| 场景 | 说法 | 效果 |
| --- | --- | --- |
| 群聊 | `/重置额度` | 只重置**当前群**今天额度 |
| 群聊 | 把今天的额度重置一下 | 同上（自然语言） |
| 群聊 | `/重置额度 100000001` | 只重置指定群 |
| 群聊 | `/重置额度 全部` | 重置今天全部群 |
| 私聊 | `重置额度` | 重置今天**全部群** |
| 私聊 | `/重置额度 100000001` | 只重置指定群 |

回复示例：

```text
已重置本群今天的额度：清掉 1.1000 元，额度 0.80 元重新满格，继续聊吧。
已重置今天全部群额度：2 个群共清掉 1.4321 元。
- 100000001（0.9876 元）、100000005（0.4445 元）
```

## 三、边界（不会误触发）

- 只有 `chat.admin.qq` 里的号能触发；普通群友说「重置额度」仍当普通聊天；
- 自然语言要同时出现「额度/预算/花费/消费」和动作词（重置/清空/清零/刷新/恢复/重开）；
- 疑问、否定句不触发：含「怎么/为什么/什么/吗/呢/？/不用/不要/别重置」等一律交给模型；
- 只清**今天**，历史日期不动；只清目标群，其他群和自己的额度配置都不动；
- 重置后会把「今日额度用完」的提醒标记一起清掉：再次用完还能收到一次提示。

## 四、实现位置

| 文件 | 改动 |
| --- | --- |
| `src/budget.py` | 新增 `BudgetStore.reset_all_today()`（清今天全部群，返回清前的花费） |
| `src/admin.py` | `handle_budget_reset()` + `_parse_budget_reset()`：权限、命令/自然语言解析、执行与回复；`HELP_TEXT` 增加命令 |
| `src/chat.py` | 命令分支和普通消息分支各接一次；重置成功后清 `_budget_notified` |
| `config/config.yaml` | `chat.admin.qq: [3871324658]` |
| `scripts/reset_budget.py` | 保留作兜底（Bot 没跑时用），注释指向新命令 |
