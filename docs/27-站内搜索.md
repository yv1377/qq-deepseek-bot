# 27 · 站内搜索（B 站 / 虎扑）

> 针对"总结昨天 IG 的比赛"这类问题：通用搜索引擎给的多是俱乐部介绍和赛程页，
> 拿不到实时赛果。这轮加了**站内搜索**：直接去 B 站搜视频、拿标题/UP主/链接再总结。

---

## 一、自检结论：为什么之前搜不到 IG 赛果

| 原因 | 说明 |
| --- | --- |
| 通用搜索偏"百科/赛程" | Bing/搜狗/360 对"昨天 IG 的比赛"返回俱乐部词条和赛程页，没有比分 |
| 缺实时赛果源 | 电竞赛果主要在 B 站/直播吧/微博的**视频与帖子**里，通用搜索覆盖差 |
| 查询没有站内指向 | 只会全网搜，不会"去 B 站搜" |

## 二、站内搜索怎么做的

### 1. B 站（可用，直接搜）

- 请求 `https://m.bilibili.com/search?keyword=...`（移动版页面是**服务端渲染**，无需登录/签名）；
- 解析视频卡：标题（`h3[title]`）、BV 号、UP 主、时长；
- 实测：搜「IG 比赛」1.1 秒返回真实视频，例如
  「【2026全球总决赛OB】瑞士轮第三轮: IG vs HLE | IG TheShy 克烈 上路视角」（UP主 ArmadylLOL）。

> 试过官方 JSON 搜索接口（WBI 签名 + buvid cookie）：首次能拿到数据，但匿名请求很快被风控返回空结果，
> 不稳定，最终改用 HTML 搜索页。

### 2. 虎扑 / 微博 / 知乎（降级）

这些站点没有稳定可解析的公开搜索页（虎扑 `search.hupu.com` 在本机 DNS 解析失败，
`m.hupu.com/search` 是 JS 空壳），所以降级为「通用搜索 + 站点名」，
并在回复里**明确标注**"该站没有公开搜索接口，以下是通用搜索里的相关内容"，不假装搜到了。

### 3. 怎么触发

| 方式 | 例子 |
| --- | --- |
| 直接说 | 「去B站搜一下 IG 比赛」→ 自动站内搜索 + 模型总结 |
| 命令 | `/search B站 IG 比赛`（同样走站内搜索 + 总结） |
| 工具 | 模型可调 `search_site(site="bilibili", query="IG 比赛")` |
| 自动预搜 | 消息里出现「B站/哔哩哔哩/虎扑/微博/知乎/贴吧/抖音」时，`_search_block` 优先走站内搜索 |

搜索结果会作为资料注入上下文/交给模型总结，并保留来源链接。
