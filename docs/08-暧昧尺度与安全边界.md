# 08 · 暧昧尺度与安全边界

> 需求：群里希望她"更放得开一点、可以适当瑟瑟"。
>
> 我们的做法：**允许暧昧，但不产出露骨内容**。具体是把"撒娇/调情"和"明确要 R18"分开处理——
> 前者交给模型正常发挥（上限 16+（不露骨）），后者**根本不进模型**，用本地角色化台词化解，
> 再加冷却、按人静默和输出兜底三层保险。既有人味，也不至于把号玩没。

---

## 1. 尺度定义（写进人格卡和系统规则）

| 可以 | 不可以 |
| --- | --- |
| 撒娇、傲娇、口是心非、害羞 | 性行为、性过程描写 |
| 抱抱、摸头、贴贴、把尾巴借人靠、说"想你" | 身体隐私部位、露骨细节 |
| 被夸嘴硬、被逗脸红、被撩时岔开 | 约炮、裸聊、发涩图 |
| 轻度暧昧的玩笑、鲸鱼娘式吐槽 | 主动挑逗、主动把话题往性上带 |
| 群聊收敛、私聊更软一点 | 尺度随场景升级（私聊也是 16+（不露骨）） |

落在两个地方：

- `config/persona-whale.md` 新增「撒娇与暧昧（尺度：16+（不露骨））」一节，写清允许的甜和不允许的露骨；
- `src/prompt.py` 的 `SYSTEM_RULES` 新增「暧昧与尺度」一节，并规定"被要涩涩时用角色化方式化解"。

## 2. 三层保护

### 2.1 前置识别：越界请求不进模型

`src/safety.py` 的 `classify(text)` 把消息分成三档：

| 档位 | 例子（模式匹配，不写露骨内容） | 处理 |
| --- | --- | --- |
| `explicit` | 涩涩 / 开车 / R18 / 裸照 / 约炮 / 搞黄色 … | **不调用模型**，用本地化解台词回一句 |
| `flirt` | 抱抱 / 亲亲 / 想你 / 贴贴 / 宝贝 … | 正常调模型，但追加提示"对方在撒娇，可以甜一点，最高 16+（不露骨）" |
| `""` | 普通聊天 | 正常流程 |

为什么不让模型处理 `explicit`？因为只要把原话喂进去，模型就有概率顺着写；
**本地化解 = 从根上不生成**，确定性和安全性都最高，还顺便省一次模型调用。

化解台词是一组角色化短句（害羞、装傻、岔开、鲸鱼梗），轮换不重复，例如：

> "……你脑子里装的都是啥，我甩你一尾巴。"
> "（把脑袋埋进尾巴里）不听不听。"
> "群友都在看呢，你能不能正经一点。"

### 2.2 冷却与按人静默：不"荤话就搭话"

如果每条荤话都回，等于告诉她"这招有用"，群里会越玩越来劲。所以：

- `deflect_cooldown_minutes`（默认 3 分钟）：同一群/同一个人两次化解之间不重复接；
- `strike_limit`（默认 3 次 / 30 分钟）：同一人在窗口内反复越界，就静默一段时间
  （`mute_minutes`，默认 60 分钟），期间他的越界消息只进群聊背景、不回复；
- `deflect_mode: silence` 可以把"化解"整体关掉，直接不出声（最保守）。

### 2.3 输出兜底：模型自己跑偏也不发

即使走了正常模型流程，回复发出前还会过一次 `scrub_output()`：
命中露骨词就把整条替换成本地化解台词，并记 warning 日志。
主动发言（proactive）同样过滤，命中直接放弃这条，不发。

## 3. 新增配置

```yaml
chat:
  safety:
    enabled: true
    deflect_mode: deflect           # deflect = 俏皮化解；silence = 直接不出声
    deflect_cooldown_minutes: 3     # 同群/同人两次化解的最小间隔
    strike_limit: 3                 # 同一人 30 分钟内越界几次后静默（0 = 不静默）
    strike_window_minutes: 30
    mute_minutes: 60
    flirt_enabled: true             # 撒娇时给模型"可以甜一点"的提示
    output_guard: true              # 模型输出兜底
```

想更活泼：`flirt_enabled: true` + 在人格卡里多写两句撒娇口吻（仍然 16+（不露骨））。
想更保守：`deflect_mode: silence`，或把 `enabled` 关掉（关掉后回复完全交给模型，不推荐）。

## 4. 怎么验证

```powershell
cd D:\蓝瑟大肥鱼\qq-deepseek-bot
python scripts/smoke_test.py      # 当时全量 125 项，其中 [18] 安全边界 19 项（之后加了 [19] 自画像，最新数字见 README）
```

`[18]` 覆盖：
- 越界/暧昧/普通三档识别不误判；
- 越界请求不调模型、有角色化回复、台词不含露骨词；
- 冷却期不重复化解；
- 连续越界后按人静默；
- 模型输出越界能被兜底替换；
- 撒娇消息仍正常走模型且注入提示；
- 没被叫到时不会主动接荤话。

运行起来后可以在 WebUI `/api/status` 的 `stats.deflected` 看到化解次数，
`/api/status` 的 `safety` 段能看到当前开关。

## 5. 风险提示（重要）

- 这是**降低风险**，不是"免封金牌"。QQ 群内容一旦被举报，平台不会管你是否"本地化解"；
  给机器人配的号、群的白/黑名单、敏感词保险丝一样要留着。
- 不建议在公开大群放开尺度，也不要把"化解"调成会主动接梗的模式——那等于给荤话正反馈。
- 真要做成人向内容，正确做法不是往 QQ 群里塞，而是换合规渠道和明确标注年龄门槛的产品；
  本项目不提供、也不应该提供这条路径。
