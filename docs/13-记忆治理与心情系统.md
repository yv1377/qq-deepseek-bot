# 13 · 记忆治理与心情系统

> 这一轮是"优化自己"的第一批：先治病（记忆越攒越杂、大图识别失败），再加一点灵魂（心情）。

---

## 一、记忆治理

### 问题（实测数据）

- `notes` 表 **744 条**，其中 743 条是记忆管家自动写的，单群最高 **612 条**；
- 抽查内容大多是一次性对话事件：「XX 发了四头像加砰的图」「谁谁别只发表情」——
  这些不是长期事实，却会挤占注入预算（每轮注入最近 5 条）；
- 笔记只增不减，没有合并机制，越聊越杂。

### 三层修法

1. **收紧抽取提示词**（`src/llm.py` 的 `MEMORY_SYSTEM`）：
   明确"只记跨会话依然有用的稳定信息"，列出该记（称呼、偏好、约定、长期在忙的事、人物关系）
   和不记（本次聊天发生了什么、谁发了什么图、一次性情绪、临时话题、复述原话），拿不准就不记。
2. **笔记合并成画像**（`_maybe_distill` / `_distill`）：
   单会话笔记累计到 `distill_every`（默认 80）条时，后台把全部笔记交给
   `llm.distill()` 按人物/主题归并成不超过 `distilled_limit`（默认 8）条画像，
   用 `memory.replace_notes()` 整体替换，来源标记为「画像」。
3. **注入优先画像**（`_memory_notes`）：
   注入时画像排最前、其余按时间从旧到新，避免最近 5 条闲聊把长期记忆挤掉。

效果：612 条零散笔记 → 8 条画像；新笔记继续积累，到阈值再合并，不会无限膨胀。

## 二、心情系统（新功能）

### 模型

- 每个会话（群 / 私聊）一份**心情能量** 0~100，平静时回到 `baseline`（默认 55）；
- 事件加减分：被夸 **+6**、被骂 **−6**、被戳 **−4**（连续戳还会额外烦）、正常聊天 **+1**；
- 按分钟衰减回 baseline（默认 0.5/分钟），所以不会一直记仇、也不会一直兴奋。

### 影响三处

| 影响 | 表现 |
| --- | --- |
| 回话语气 | 环境块注入「【你现在的心情】…」：心情好更甜更活泼；烦躁时话短、不接无聊梗 |
| 自画像 | 发自拍时按心情选图：开心→比心图，平静→日常图，烦躁→生气图（`portrait.json` 的 mood 字段） |
| 戳戳容忍度 | 心情能量 < 30 时，第 1 次戳就直接用强攻击台词（不用等连续 3 次） |

### 命令

- `/mood` 或 `/心情`：任何群友都能问她现在心情怎么样（公开，不需要管理员），
  输出能量、标签、最近 3 个心情事件（如「被夸+6；被戳-4」）。

## 三、大图识别修复（顺带）

QQ 原图经常 8~13 MB，之前超过 7.6 MB 就直接拒绝识别（日志里 4 次失败）。
现在：

- `vision.max_image_bytes` 默认 **32 MB**（下载硬上限），像素上限放宽到 4000 万；
- 下载后统一缩到 768px、JPEG 再送视觉模型，所以大图不再失败，token 也不会涨。

## 四、配置

```yaml
chat:
  memory:
    distill_every: 80        # 单群笔记累计到多少条自动合并成画像（0 = 关闭）
    distilled_limit: 8       # 合并后保留几条画像
  mood:
    enabled: true
    baseline: 55             # 平静时的能量
    decay_per_minute: 0.5    # 每分钟回落到 baseline 的速度
```
