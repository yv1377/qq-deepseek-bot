# 16 · 成绩单页面与热点词

> 这一轮把「我现在的状态」做成一个能看懂的页面：打开浏览器就能看我今天干了什么、心情如何、
> 和群里谁最熟、最近大家在聊什么。

---

## 一、成绩单页面

访问：<http://127.0.0.1:8080/dashboard>（主页右上角也有「📊 成绩单」入口）

页面卡片：

| 卡片 | 内容 |
| --- | --- |
| 今日概览 | 运行时长、收到/回复/跳过/出错、戳戳回复数、防刷屏数、模型 |
| 心情 | 每个群的能量条 0~100 + 标签（很开心/还不错/平静/有点烦/很生气） |
| 亲密度排行 | 每个群 top5：昵称 + 等级 + 分数 |
| 记忆规模 | 消息 / 归档原文 / 笔记 / 画像 / 待办 / 活跃会话 |
| 图库 | 自画像张数、表情包张数、磁盘占用 |
| 本群热点词 | 近 7 天群友消息的高频词云（字号 = 次数） |
| 今日预算 | 每个群今天花了多少 / 每天上限 |
| 近 7 天用量 | 日期、调用次数、tokens、平均耗时 |
| 待办 | 未完成提醒数量 |

- 每 30 秒自动刷新，token 与主页共用（localStorage 里的 `dsh_web_token`）；
- 数据来自新接口 `GET /api/dashboard`（需要 WEB_TOKEN）。

实现：`src/dashboard.html`（自包含页面）+ `webui.py` 的两个端点（`/dashboard`、`/api/dashboard`）
+ `ChatService.dashboard_data()`（聚合 runtime_status / memory / 亲密度 / 词云 / 用量 / 图库 / 提醒）。

## 二、热点词怎么算的

`src/text_stats.py`：

- 中文按 **2-gram** 统计（不引第三方分词库，够用且快）；
- 英文按 ≥3 字母的单词统计；
- 过滤常见虚词与机器人自己的词（"我们/什么/这个/大肥鱼/表情…"）；
- 只统计**群友**消息（不含 bot 自己的回复），取近 7 天、默认 top 30、出现 ≥2 次。

## 三、`/report` 手动群报

每日群报默认 22:30 发、且默认关闭。想立刻看效果：

```
/report    （或 /群报）
```

会无视 `enabled` 开关强制生成并发送一条本群群报；消息太少会回「今天消息太少，暂时没凑出群报」。
