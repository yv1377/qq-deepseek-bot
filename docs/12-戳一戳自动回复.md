# 12 · 戳一戳自动回复

> 需求：有人戳头像（QQ「戳一戳」）时要自动回；回复不能太千篇一律；
> 如果连续戳了三条，直接切更不耐烦性回复。

---

## 1. 事件从哪来

QQ 的戳一戳在 OneBot v11 里是 **notice 事件**，不是 message：

```json
{
  "post_type": "notice",
  "notice_type": "notify",
  "sub_type": "poke",
  "group_id": 123456,
  "user_id": 20001,     // 戳的人
  "target_id": 999      // 被戳的人（机器人）
}
```

`src/onebot.py` 新增 `parse_poke()`：

- 只认 `notice_type` 为 `notify`（`sub_type=poke`）或 `poke` 两种写法；
- **只处理 target_id 等于机器人自己**的事件，群友互相戳不管；
- 群聊 → `kind="group"`，私聊 → `kind="private"`；
- 合成一个 `message_id`（`poke:时间:用户:目标`）用于去重；
- `_on_raw` 原来遇到非 message 事件直接丢掉，现在 notice 分支会把它交给 `ChatService.handle`。

## 2. 回复怎么做到不千篇一律

三层：

1. **台词池**：普通回复 10 条、更不耐烦 10 条（互损群另有一套更狠的 8 条），写在 `src/chat.py` 顶部；
2. **避免连续重复**：每个「会话 + 人」记住最近用过的 4 条，随机只在没用过的里挑；
3. **按人独立**：A 连续戳和 B 戳互不影响计数，也不互相占用台词。

## 3. 连续三次 → 更不耐烦

`src/chat.py` 的 `_handle_poke()`：

- 按「会话 + QQ 号」记录戳的时间戳，窗口 `window_seconds`（默认 120 秒）；
- 窗口内第 1、2 次 → 普通台词；**第 `angry_after` 次（默认 3）起 → 更不耐烦台词**；
- 窗口过期自动清零，重新从普通台词开始；
- 私聊同样生效；群被静音 / 群在黑名单 / 用户被拉黑时不回；
- 不写会话记忆（避免污染上下文），只写群聊背景，所以下次聊天时她"知道刚才被人戳烦了"。

更不耐烦也有底线（和 docs/08 一致）：

- 只骂**行为和手**（"手不要了是吧""找骂是吧"），不带家人、外貌、疾病、地域、性别等；
- 只有配置了 **群专属口吻规则**（`persona.group_rules`）的互损群才用粗口版，
  其他群用"凶但不脏"的版本；
- 台词都是玩笑式威胁，不涉及真实伤害。

## 4. 配置

```yaml
chat:
  poke:
    enabled: true
    window_seconds: 120    # 连续戳戳的统计窗口（秒）
    angry_after: 3         # 窗口内第几次开始更不耐烦
```

想改成"戳第二次就凶"：`angry_after: 2`；想让她永远好脾气：`enabled: false`。

## 5. 验证

```powershell
cd D:\蓝瑟大肥鱼\qq-deepseek-bot
python scripts/smoke_test.py     # 全量 180 项，其中 [23] 戳一戳 11 项
```

`[23]` 覆盖：

- 戳机器人自己触发、戳别人不触发、非 poke 通知不触发、普通消息不误判；
- 戳戳会回复、回复不重样；
- 第 3 次切更不耐烦台词；
- `stats.pokes` 计数；
- 换个人戳仍是普通回复；
- 私聊戳也会回；
- 窗口过期后重新从普通台词开始。

## 7. 备注

- NapCat 默认会推送 notice 事件；如果戳了没反应，先确认 WebSocket 没过滤 notice。
- 台词池在 `src/chat.py` 顶部（`_POKE_LINES` / `_POKE_ANGRY_LINES` / `_POKE_ANGRY_HARSH`），
  想换口吻直接改那里，不用动逻辑。
