# 大肥鱼表情包插件（dsh-nekowhale-stickers）

上游：[Loping151/dsh-nekowhale-stickers](https://github.com/Loping151/dsh-nekowhale-stickers)
（Apache-2.0 代码 / CC BY-NC 4.0 知识库；作者：B站 可以叫我云大人，kiriyuki.com）

## 桌面端

已安装到 DSH 桌面 profile：

```powershell
dsh plugin --profile desktop add dsh-nekowhale-stickers
```

当前依赖版本：`dsh-nekowhale-stickers ^1.1.1`；DSH 技能目录已出现 `nekowhale-stickers`。
桌面端提供大肥鱼网页桌宠、表情设置、`sticker_search` / `sticker_send` / `meme_render` /
`sticker_manage` 等完整能力。

## Bot 端

Bot 是 Python 进程，不能直接加载 DSH 的 TypeScript 插件，因此使用**同一份知识库**做原生适配：

- 知识库文件：`data/neko/nekowhale.json`（322 张表情，含情绪/标签/描述/方向）；
- 图片按需从 `kiriyuki.com` 拉取 GIF，不落进普通 meme 图库；
- 所有群可用：
  ```text
  /neko 摸鱼
  /表情包 被夸
  /贴纸 下班
  ```
- 模型也可以调用 `sticker_search` / `sticker_send`；`sticker_send` 返回 `[sticker:名字]`
  标记，Bot 的 `_deliver` 会替换成真实表情图片；
- 与图片扫描/图片记忆完全独立：不会写入 `image_memory`，不影响视觉理解。

## 自动穿插

`chat.neko.enabled: true`、`auto_chance: 0.05`：每次成功文字回复后，独立 5% 概率
自动补一张大肥鱼表情包 GIF；与旧图库配图互斥，一轮最多一张，不会双图。
认真/难过/考试/求助等语境自动跳过。手动 `/neko` 不受此概率影响。
