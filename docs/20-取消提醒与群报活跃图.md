# 20 · 取消提醒、群报活跃图与命令帮助

> 这一轮补三个小洞：提醒能取消、群报图片里能看到活跃度、`/help` 里能看到她所有命令。

---

## 一、提醒可以取消了

之前提醒只能加、不能删。现在：

```
/reminders      看本群还没完成的提醒（编号）
/forget 3       取消 #3 号提醒
```

- 只能取消**本会话**的提醒，不能跨群删；
- 取消不存在的编号会回「没找到 #N 这个提醒」，不会假装成功；
- 实现踩过一个坑：最初用「删完再查还在不在」判断成功，导致「本来就不存在」也返回成功——
  已改成**先查存在再删**。

## 二、群报图片里加了活跃小图

`render_report_card()` 新增 `activity` 参数：在群报图片的看点下方、数据脚注上方，
画一条 7 天迷你柱状图（今天高亮）。每天 22:30 发的那张图现在能看到：

```
● 今天的看点 1
● 今天的看点 2
近 7 天活跃  ▁ ▁ ▁ █ ▅ ▂ ▁
今日消息 164 条 · 由大肥鱼自己生成
```

## 三、`/help` 更新

原来只有管理员命令；现在分两段：

```
【谁都能用】
/mood /card /doctor /remind /reminders /forget /report /affinity
【管理员】
/help /status /notes /todos /reset
```
