# 14 · 定时提醒与自检

> 这一轮加的两件事：**答应了的事要真的会响**（定时提醒），**我自己的状态要能一眼看清**（`/doctor`）。

---

## 一、定时提醒

### 怎么用

三种入口，随便哪种都行：

1. **自然语言**（她调工具）：
   > 群友：明天早上 8 点提醒我交报告

   模型识别到"提醒"意图，调用 `add_reminder(when="明天早上8点", content="交报告")`；
2. **命令**：
   ```
   /remind 明天早上8点 交报告
   /remind 30分钟后 喝水
   /reminders        # 看本会话还没完成的提醒
   ```
3. **到点自动发**：后台调度器每 30 秒检查一次，到期就发
   「⏰ 到点啦：交报告」，群里/私聊都支持。

### 支持的时间说法

| 说法 | 解析结果 |
| --- | --- |
| `30分钟后` / `2小时后` / `半小时后` | 相对当前时间 |
| `明天早上8点` / `后天下午3点` | 指定日期 + 时刻 |
| `今晚9点半` / `明晚8点` | 晚间自动按 21:30 / 20:00 算 |
| `8点`（当前已过 8 点） | 顺延到明天 8 点 |
| `明天`（没说时间） | 明天 9:00 |

解析不了会回一句「没听懂时间，可以说『明天早上8点』『30分钟后』这种」，不会乱记。

### 实现

- `src/reminder.py`：自然语言时间解析（`find_time` / `parse_remind_time` / `parse_reminder`）
  + `ReminderScheduler`（后台循环，`tick_once()` 可单步测试）；
- `src/memory.py`：新增 `reminders` 表与 `add_reminder` / `due_reminders` /
  `mark_reminder_done` / `list_reminders`；
- `src/chat.py`：`/remind`、`/reminders` 命令与 `send_reminder()`（到点由调度器调用）；
- `src/tools.py`：新增 `add_reminder` 工具（模型可自然调用）；
- `src/main.py`：启动/停止提醒调度器；
- 群被静音时到点不发（避免打扰）。

## 二、`/doctor` 自检

一条命令看全身：

```
/doctor   （或 /体检、/自检）
```

输出示例：

```
🩺 自检报告（运行 3h12m）
- 协议端：已连接｜模型 deepseek-chat
- 今日：收 128 / 回 96 / 跳过 30 / 错 0
- 视觉：deepseek-flash（单图上限 32MB）
- 记忆：消息 70 / 归档 2166 / 笔记 744（画像 8）/ 待办 2
- 图库：表情包 326 张 / 130 MB；自画像 7 张
- 预算：每群每天 0.3 元，今日 100000001:0.066元
- 心情：100000001:54有点烦
- 提示：图库偏大（可压缩）
```

检查项：协议端连接、模型、今日收发/错误、视觉配置与上限、记忆库规模（含画像数）、
图库张数与磁盘占用、今日预算、各群心情，最后给一条自动诊断"提示"。

公开可用（不含密钥/隐私），谁发都能看。

## 三、配置

```yaml
chat:
  remind:
    enabled: true
    check_interval: 30    # 每多少秒检查一次到期提醒
```
