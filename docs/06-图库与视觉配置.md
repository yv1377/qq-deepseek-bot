# 图库与视觉识别（图片 / GIF / 表情包）

大肥鱼不会自动解读群里的每一张图：**只有明确问了「图里是什么 / 上面写的什么 / 看看这张」时**
才调用 DeepSeek‑V4.1‑Flash 识别，把一句描述塞进当前对话；普通发图不会触发视觉，也不会逐张点评。

图库 WebUI：重启智能体后访问 <http://127.0.0.1:8080/gallery>，输入群号打开图库。
可浏览 GIF、筛选收藏来源、搜索并收藏图片，以及填写图片的适用场景标签。
图库文件在 `data/memes/<群号>/`；图片旁的 JSON 保存描述、标签和来源。
不同群隔离，重启保留。允许参与的群内图片会后台收藏，同一张图只处理一次
（按内容哈希 + QQ 文件名去重），不会反复下载/识别/入库；收藏到的描述只留在图库里
供配图匹配，不再塞回群聊背景，避免它逐张讲解图片。

非 @ 消息独立抽取 15% 概率回复，@ 保留必触发；过滤、禁用和静音仍生效。
成功文字回复后独立抽取 20% 概率尝试配图，优先按当前消息、回复和图片描述/标签的关键词匹配；
匹配不到就随机发一张本群表情包（图库为空时才只发文字），实际发图比例仍受概率控制。
目前不是视觉向量检索或模型权重训练。

## 按需识别：问了才看图

触发条件（满足任一才会调用视觉模型）：

- **@ 她并带图**：视为直接让她看，哪怕没写问句；
- 消息里明确问图片内容：「图里是什么 / 是谁 / 上面写的什么 / 看看这张 / 识别一下 / 描述一下」；
- **引用一张图再问**：会通过 `get_msg` 找回被引用的原图；
- **刚发过图、3 分钟内紧接着问**：用同一人刚发的那张；如果问的人 @ 了她，
  也会用本群最近一张图兜底。识别一次后即清掉，避免反复花钱。

普通发图、没提问时不会触发视觉，也不会描述。系统规则额外禁止她说
“我看不到图 / 是白框 / 图没了”，避免明明有视觉却装瞎。

`config/config.yaml` 默认配置：

```yaml
vision:
  enabled: true
  base_url: https://api.deepseek.com
  model: deepseek-flash        # 输入支持 text + image
  api_key_env: DEEPSEEK_API_KEY
  max_tokens: 200
  disable_thinking: true
```

`.env` 里只要填了 `DEEPSEEK_API_KEY` 就能用，**不需要另外买视觉模型**。
`VISION_API_KEY` 留空时会自动复用 DeepSeek 的 Key；想换成 SiliconFlow、智谱等
OpenAI 兼容视觉服务时，再单独填 `VISION_API_KEY` 并改 `base_url` / `model`。

两个容易踩的坑已经默认处理好：

- **必须关闭思考**：`deepseek-flash` 默认会先推理。推理 token 会计入 `max_tokens`，
  推理没结束正文就是空的，图片描述会丢。`disable_thinking: true` 会发送
  `thinking: {"type": "disabled"}`；换成不认识该字段的服务时自动重试去掉它。
- **描述要短**：默认 prompt 只要求 40 字以内，且明确告诉模型“不要复述图片内容”，
  避免每条图片消息都把上下文撑大、也避免它逐张讲解。

请使用服务商实际支持的模型名称，不要把纯文字模型名称直接填进来（`deepseek-v4-pro` 不支持图片输入）。
识别失败保留原图并降级为 `[图片]`，可手动打标签；旧图库图片也可调用
`POST /api/gallery/<群号>/<文件名>/recognize` 重新识别。
视觉调用会向配置的服务发送图片/抽帧。未配置时不伪造视觉描述。

## GIF 动图

GIF、动态 WebP、APNG 不会只取第一帧：程序均匀抽取最多四帧（转 JPEG），
按时间顺序一起交给视觉模型，所以能描述“红球从左向右移动”“眼睛左右转动”这类动作变化。
发送和图库保留原始动图，抽帧只用于识别，可能漏掉一闪而过的短暂动作。
QQ 的 `mface` 表情包如果带 `summary`（如「狗头」），名字也会写进消息文本；
即使视觉模型暂时不可用，模型也知道发的是哪个表情。

## 表情包

NapCat / OneBot 模式默认启用 `chat.memes`，只收集**表情包类**：
QQ 标记为表情包的图片（`image.sub_type=1`、`7`）、带 `summary` 的表情、
`mface` 商城表情；普通照片默认不入库（`collect_all_images: false`），
不会“什么图都存”。GIF 动图表情照常收藏。

同一张表情包重复出现时只入库一次，之后需要配图时直接从图库调用；
收藏时自动写一句短描述（用于语境匹配），没有描述时也不影响聊天。

下载只允许 QQ 官方图床：`*.qpic.cn`（含 `gchat.qpic.cn`）、
`multimedia.nt.qq.com`、新版 `multimedia.nt.qq.com.cn`、商城表情原图
`gxh.vip.qq.com`，不跟随重定向、不访问群友贴的任意网址。
@、静音、黑名单、被过滤的消息不参与收集。

## 删除图片

- 群里 @她并**回复那张图**说「删掉这张 / 删除这张表情包」：机器人用 `get_msg` 取回被引用图片的
  URL，下载后按内容哈希匹配图库文件，删掉图片和旁边的 JSON；
- 不引用图时，@她说「删掉刚才那个表情包」：删除本群最近一次发出去的那张；
- 直接发一张图并 @她说「删掉」：删除这张图在图库里的收藏；
- WebUI 图库每张图下方也有「删除」按钮（`DELETE /api/gallery/<群号>/<文件名>`）；
- 只删图库，不撤回 QQ 消息；删除不需要管理员，但会记录操作日志。找不到会明确提示“图库里没找到”。

## 搜索图片

在图库输入关键词点击“搜索并收藏”，或在群里说“帮我搜几张橘猫图片并收藏”。
独立的 `search_images` 工具从 Wikimedia Commons 查找、下载最多三张，记录来源及授权元数据。
普通 `web_search` 是文字搜索，不会把网页随意当图片下载。
搜索依赖外网，失败会明确提示；图库可打开来源页查看作者和授权。

单张最多 5MB、每群最多 200 张；满后停止收藏，不自动删除已有文件。
WebUI 默认只监听本机；如配置 WEB_TOKEN，图库 API 和图片访问同样要求令牌。

## 重启生效

视觉配置和代码修改都需要重启智能体才生效。如果旧机器人还在后台跑，直接双击
`D:\蓝瑟大肥鱼\restart_bot.bat`：它会结束占用 8080 端口的旧进程、打开新的机器人窗口，
并自动打开状态页。看到状态页右上角「图片理解: 开」就说明视觉已启用。
只想正常启动时仍用 `start_bot.bat`。

## 自测

```powershell
python scripts/vision_live_test.py   # 真实调用模型：静态图 / GIF / 表情包 / 图库 / 端到端聊天
python scripts/smoke_test.py         # 离线回归（含视觉客户端协议、降级）
python scripts/gallery_test.py       # 动图抽帧 + 图库鉴权（Mock，不联网）
python scripts/memes_test.py         # 收藏 / 去重 / 发送（Mock，不联网）
```

`vision_live_test.py` 会本地起一个 HTTP 服务提供测试图片，不依赖外网图床；
它真的消耗少量 DeepSeek token。识别结果示例：

- 静态图：`画面是一个橙色圆脸、尖耳、黑眼、粉鼻并带胡须的卡通猫头…`
- GIF：`浅灰背景上写有“GIF 动画”，红圆点从左向右移动，左下角帧数递增…`
- 表情包：`黄色背景上画着大眼微笑简笔画脸，下方写着“摸鱼中”，透着轻松俏皮…`

## 图片记忆（持久化）

- 每张识别过的图会写进 `data/bot.db` 的 `image_memory` 表：`session_id / user_id / name / description / media_key / created_at`；
- 同一会话同一 `media_key`（URL 或 QQ 文件路径）只保留最新描述，每会话最多 200 条；
- 之后每次回复会把最近 5 条图片记忆以【最近看过的图】注入当前消息，可以自然引用（“你刚才那张…”）；
- 看不懂图反问后，群友的解释会通过 `update_latest_image_memory()` 补进最近一条记忆，做到“越聊越懂”；
- 图片记忆只存文字描述，不下载/不长期保存原图；删除会话时不会自动清图片记忆（目前按条数滚动淘汰）。

### 2026-10-26 补充：隐私图拦截 / 待删标记 / 表情表达

- 新收藏图片在视觉描述（或配文/上下文）命中身份证、银行卡、手机号、地址、二维码、
  聊天记录、密码、token、后台截图、裸露等隐私关键词时，不入库并删除临时文件。
- 已有图库可运行：
  - `python scripts/meme_admin.py privacy-scan` 只看；
  - `python scripts/meme_admin.py privacy-scan --apply` 删除命中的隐私风险图。
- 群友/主人说「删掉这张图/表情包」时，不再立即删除，而是写入 `data/memes/pending_deletions.json`
  待删标记；主人确认后运行 `python scripts/meme_admin.py pending` 查看，
  `python scripts/meme_admin.py purge` 统一清理。
- 图片记忆新增 `expression`：后台识图时结合前后聊天，让文本模型推断这张图/表情包
  想表达的情绪、态度或梗，写进图片记忆和群聊背景；明确问图时也会附加“表达意味”。
  关键词：`vision.infer_expression`、`vision.expression_max_tokens`。
