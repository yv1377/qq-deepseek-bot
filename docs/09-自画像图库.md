# 09 · 自画像图库（让她知道自己长什么样）

> 需求：给 bot 弄一套「蓝色鲸鱼娘」的照片，开个图库让她能调用，并且她要知道自己长什么样。
>
> 参考形象：B 站两个视频里的蓝色鲸鱼娘
> - [【大肥鱼】我的悲伤是token做的](https://www.bilibili.com/video/BV1uLpn6PEgz/)（UP：钟晴的少女心事，角色形象来源：@ZipZipPipe）
> - [【领域展开】意气风发啊，大肥鱼](https://www.bilibili.com/video/BV1YSnJ6AE3y/)（UP：增殖的发呆）
>
> **只参考角色特征，没有使用画师原图**：我们是程序化重绘一套自己的版本，无版权素材。

## 2. 图片怎么来的

`scripts/make_self_portraits.py` 用 Pillow 在 768×768 逻辑画布上 2 倍超采样绘制，
所有部件都是「形状并集 + 自动描边」的圆润画法，背景是深海渐变 + 光柱 + 气泡 + 海草剪影。

```powershell
cd D:\蓝瑟大肥鱼\qq-deepseek-bot
python scripts/make_self_portraits.py
# 输出 data/self/
#   01-normal.png  02-shy.png  03-angry.png
#   04-eating.png  05-wave.png 06-heart.png
#   portrait.json  清单（外观设定 + 每张图的描述/表情）
```

想改形象：改脚本里的配色/坐标/道具，重跑即可；想加表情就加一个 `STYLES` 项。

## 3. 让她「看过自己」

`scripts/describe_self_portraits.py` 会调一次视觉模型（复用 `config.yaml` 的 `vision` 配置，
默认 DeepSeek）逐张描述自己的照片，写回 `portrait.json`：

```
01-normal.png -> 蓝发蓝眼、戴白色头饰与蓝色蝴蝶结的动漫女孩，画面无文字。
02-shy.png    -> 蓝色调卡通女孩闭眼微笑，戴白色圆球头饰与蓝色蝴蝶结，穿白裙配蓝宝石领结…
```

这一步的作用：图库里的每张图都有「她自己看过并留下的描述」，不是空文件；
同时 `portrait.json` 的 `appearance` 字段是她的外观设定，会被注入系统提示词，
所以她回答「你长什么样 / 你头发什么颜色」时有据可依，而不是瞎编。

```powershell
python scripts/describe_self_portraits.py   # 会消耗少量视觉模型 token；失败会保留兜底描述
```

## 4. 图库怎么用

- `src/self_gallery.py`：加载 `data/self/`，对外提供 `appearance` / `about()` / `pick()`；
- `chat.self_portrait` 配置（**默认开启**）：

  ```yaml
  chat:
    self_portrait:
      enabled: true
      directory: data/self
      cooldown_minutes: 3   # 同群/同人两次发自拍的最小间隔
  ```

- 触发词（命中且这条消息本来就该回复时）：`自拍`、`长什么样`、`长啥样`、`你长得`、
  `看看你`、`你的照片`、`你本人`、`发张你的` 等；
- 命中后**不走模型**：直接从图库挑一张发出去（绕过"模型不能发图"的限制），
  再跟一句角色化台词（"喏，这就是我。别嫌画得素啊。"），并按群/按人冷却防刷屏；
- 群聊走 `send_group_image`，私聊走新增的 `send_private_image`；
- 外观设定会拼进 system（后缀），她平时聊天也知道"自己长这样"；
- 图库为空时不崩：回一句「我还没存下自己的样子……」。

## 5. 为什么不直接爬网图

- **版权**：B 站/微博/pixiv 上的鲸鱼娘是画师作品，直接存图发群是侵权；
- **形象不统一**：不同画师画出来差别很大，她会"精神分裂"；
- **网络受限**：本机实测 Openverse / Wikimedia 都连不上，Bing 图片页能开但直链批量下载不稳定。

所以"参考特征 + 程序化重绘"是更稳的解法：形象统一、可迭代、可复现、无版权问题。
以后真想换成更精致的图（比如自己画的/约的稿），只需替换 `data/self/*.png`（或 `.jpg`）
并更新 `portrait.json` 的 `file` 与 `appearance`，代码不用动。

### 5.1 当前主形象（用户提供的女仆鲸鱼娘）

- 文件：`data/self/00-portrait.jpg`（400×711，用户提供的角色图）；
- `portrait.json` 里该条目带 `"primary": true`；被问「发张自拍/你长什么样」时优先发这张，
  其他表情图（shy/angry/eating…）留给指定情绪的场景；
- 同文件里的 `appearance` 是细致外观设定，`image_prompt` 是可直接复用的英文出图提示词；
- 外观设定会注入 system，所以她知道自己的发色、女仆装、鲸鳍耳饰、鲸尾和招牌动作。

## 8. 想换成画师那版？（版权与替换）

参考形象（@ZipZipPipe 的蓝色鲸鱼娘）是**画师作品**，我们只参考特征、没有使用原图。
直接抓原图存进图库再发给群，属于未经授权的复制与传播：既是对画师的不尊重，
也是群里最容易被举报、最容易把号玩没的一类内容。

如果确实想要"画师那只"，两条合规做法：

1. **找画师授权**：私信说明用途（个人 QQ 群机器人、非商用、会署名），
   拿到同意后把图放进 `data/self/`，在 `portrait.json` 里补上
   `"attribution": "形象：@ZipZipPipe（已授权）"`，代码不用改；
2. **自己约稿 / 自己画**：同样丢进 `data/self/`，更新 `portrait.json`
   的 `items[].file` 与 `appearance` 即可。

替换步骤（不需要动代码）：

```powershell
# 1) 把新图放到 data/self/（png/jpg 都行）
# 2) 改 data/self/portrait.json：
#    items 里加 {"file": "新图名.png", "mood": "normal", "description": "...", "tags": "自画像"}
#    appearance 改成她真实的样子
# 3) 重启 bot（appearance 在启动时注入 system）
python scripts/describe_self_portraits.py   # 可选：让视觉模型重新看一遍
```
