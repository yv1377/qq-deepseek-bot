## 二、代码同步：`scripts/sync_to_cloud.ps1`

原理：本机 `tar` 打包代码 → `scp` 上传 → 云端解包覆盖（**不动云端 data/**）。

```powershell
# 只同步代码
.\scripts\sync_to_cloud.ps1 -Server 123.45.67.89 -User root -RemotePath /opt/qq-deepseek-bot

# 用密钥登录（推荐）
.\scripts\sync_to_cloud.ps1 -KeyFile C:\Users\you\.ssh\id_ed25519

# 同步后远程重启
.\scripts\sync_to_cloud.ps1 -Restart
```

同步内容：`src/ scripts/ config/ docs/ requirements.txt README.md`
不同步：`data/`（云端自己的数据库/表情包/画像）、`.git/`、`.venv/`、`__pycache__/`。

## 三、远程运维：`scripts/remote_bot.ps1`

```powershell
.\scripts\remote_bot.ps1                  # 进程 + 端口
.\scripts\remote_bot.ps1 -Action logs     # 最近 100 行日志
.\scripts\remote_bot.ps1 -Action restart  # 重启
.\scripts\remote_bot.ps1 -Action shell    # 直接 SSH 进去
```

云端启动命令默认是 `python3 scripts/startup.py`；如果云端用 Docker/systemd 部署，
用 `-StartCommand` / `-StopCommand` 覆盖，例如：

```powershell
.\scripts\remote_bot.ps1 -Action restart `
  -StartCommand "cd /opt/qq-deepseek-bot && docker compose up -d" `
  -StopCommand "cd /opt/qq-deepseek-bot && docker compose down"
```

## 四、需要准备的东西

1. **SSH 凭据**：用户名（root / ubuntu）+ 密码，或密钥文件路径；
2. 云端部署方式：裸 Python？Docker？systemd？→ 对应 `-StartCommand`；
3. 确认云端 8080 安全组已放行（否则网页版打不开）、NapCat 的 3001 与本机不需要互通。

## 五、以后的工作流（改代码 → 上云）

1. 本机改代码、跑 `python scripts/smoke_test.py`；
2. `git commit`（有版本可回滚）；
3. `.\scripts\sync_to_cloud.ps1 -Restart` 一键同步 + 重启；
4. `.\scripts\remote_bot.ps1 -Action logs` 看云端日志确认连上 NapCat。

## 六、避免「两个实例互踢」

同一个 QQ 账号（1234567890）**只能有一个地方登录**。本机与云端同时跑会互相顶号，
表现就是 bot 随机掉线、有时不回消息。所以：

- 用云端时，本机 QQ / NapCat / bot 保持关闭（本轮已停）；
- 本机只负责改代码 + 同步，不登录 QQ。

## 七、Git 仓库同步（推荐长期方案）

### 首次配置（只做一次）

1. **创建私有仓库**（Gitee 国内最快）：
   - https://gitee.com → 新建仓库 → 名称 `qq-deepseek-bot` → **私有** → 不要勾选 README 初始化；
   - 复制仓库地址：`https://gitee.com/你的用户名/qq-deepseek-bot.git`
2. **生成私人令牌**：Gitee 头像 → 设置 → 私人令牌 → 生成 → 勾选 `projects`（仓库读写）。
3. **本机首次推送**：
   ```powershell
   cd D:\蓝瑟大肥鱼\qq-deepseek-bot
   .\scripts\push_to_git.ps1 -RepoUrl "https://gitee.com/你的用户名/qq-deepseek-bot.git" -Token "你的令牌"
   ```
4. **云端首次克隆**（在 OrcaTerm 里）：
   ```bash
   sudo mkdir -p /opt/qq-deepseek-bot
   sudo git clone https://oauth2:你的令牌@gitee.com/你的用户名/qq-deepseek-bot.git /opt/qq-deepseek-bot/code
   ```

### 以后每次改代码

- 本机：`.\scripts\push_to_git.ps1 -RepoUrl ... -Token ...`（会提交 + 推送）
- 云端：`bash /opt/qq-deepseek-bot/code/scripts/cloud_git_pull.sh`（拉取 + 同步到容器 + 重启）

或者云端加定时自动拉取（每 5 分钟）：

```bash
crontab -e
*/5 * * * * bash /opt/qq-deepseek-bot/code/scripts/cloud_git_pull.sh >> /home/ubuntu/git_pull.log 2>&1
```

### 安全提示

- 令牌只保存在命令历史/环境变量里，不写进代码（`.gitignore` 已排除 `.ssh/`、`.env`）；
- 令牌可以随时在 Gitee 撤销重发；建议只给 `projects` 权限。
